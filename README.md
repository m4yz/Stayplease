# StayPlease Dashboard

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard supports:
- Uploading a Task Report Excel file
- KPI cards for total/completed/to-do/in-progress/completion rate
- Team and status analysis
- Daily activity trends
- Urgent task monitoring
- Team/assignee performance
- Searchable task explorer
- CSV export of filtered data

The Excel structure is based on the supplied Task Report export.
